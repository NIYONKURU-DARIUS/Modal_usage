# 🪟 React Native Modal Usage (`Modal_usage`)

A focused React Native application created with Expo demonstrating how to implement and control the `<Modal>` component in mobile and web applications.

---

## 🎯 What This App Demonstrates

- **`<Modal>` Component**:
  - `visible`: Controlled via React boolean state (`modalVisible`).
  - `animationType="slide"`: Smooth sliding transition on opening and closing.
  - `transparent={true}`: Overlays on top of the parent view with a semi-transparent dark backdrop.
  - `onRequestClose`: Native back button handler for Android devices.
- **State Toggle**: Clean handlers for opening and closing the modal with custom buttons.

---

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npx expo start
```

Press `w` in your terminal to open in web browser, or scan the QR code using the Expo Go mobile app.
